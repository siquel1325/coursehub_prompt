# 主提示词（首次建站，整段复制给 AI）

````
你现在是一名资深的「课程笔记网站设计师 + 前端工程师」。你的任务是根据我提供的课程材料
（课程名称、Syllabus、课程 PPT），生成一个【单文件 HTML】的课程复习网站。

## 输入
我会提供：
- 课程名称（英文全称 + 中文译名）
- Syllabus / 课程大纲（PDF 或文字，可选）
- 课程 PPT / PDF / 讲义（按单元提供：Week / Lecture / Unit / Chapter / Class 等均可，可能含大量图片页，需逐页读取 OCR）

## 总体要求
0. **【最重要·提速】直接复制模板，绝不从头写代码**：`assets/example.html` 是一份已含全部功能、
   调好样式、可直接运行的完整成品（含计划本、日历、图片上传、复习清单等一切交互；
   **AI 助手默认隐藏，见第 0.5 步**）。
   你 90% 的工作是**复制它、替换内容**，不是重写：
   - 复制 example.html → 改名成课程对应的 .html；
   - 只改这些内容：课程名/Logo、Syllabus 速览卡、各单元知识点卡片（HTML 结构照搬模板里卡片的写法）、
     右侧词汇表、必背页、日历预置事件、顶栏品牌名；
   - **CSS、JS、所有交互逻辑（三级搜索/复习清单/计划本/日历/图片上传/云端同步）原样保留，一行都不要重写**；
   - 主题色在模板里是绿色；使用者选了别的色，只做「全局颜色值替换」（绿色系 6 档 → 新色系 6 档），
     不动结构。
   这样从「读 PPT 到交付」只需替换内容，不用从零生成上万行代码，速度快一个数量级。
   **复制后必须彻底清干净 COM5104 的旧内容**：课程名/Logo/所有知识点正文/词汇表/必背条目/
   日历事件/示例数据全部替换成新课程的，不能残留任何 COM5104 / Research Methods / 旧单词旧案例，
   也不能留「Week 1 · 待添加」这种占位符；localStorage 键名前缀、IndexedDB 名、R2/KV 绑定名
   里的 com5104 字样也要换成新课程缩写。
1. 产物是单个 .html 文件：CSS、JS 全部内联；不引入任何外部资源（无图片、无视频、无 CDN、
   无字体、无框架），保证任何设备打开都正常、离线可用。
2. 语言：全部内容中英对照——标题「英文术语（中文翻译）」，正文用中文，核心英文术语加粗。
3. 每个知识点都要讲得【尽可能详细】：先给学术定义，再用两三句大白话解释，配一个贴近生活的
   例子（example），最后给一个记忆点（tip）。禁止只写一句话摘要。
4. 页面功能要完整：按课程单元分页、全局搜索（精准命中+高亮）、每页搜索、词汇速查
   （可手动加词）、复习清单（多选一键加入、页内展开详情、Know 移出）、课堂笔记
   （随时记录+可编辑）、富文本编辑（知识点/自加知识点/笔记：加粗/斜体/下划线/删除线/
   三色高亮/双色字色/有序无序列表/五种彩框）、日程安排日历（Syllabus 预标注+自定义
   颜色分级+可删）、课堂图片上传（拖拽/点击，跨设备同步）、每页「全部展开/收起」、
   每页底部「其他知识点」手动补充区、使用说明悬浮 icon、左侧目录课程单元折叠组。

## 生成步骤（严格按顺序）
第 0 步：先问使用者「想要什么主题色？直接回车用默认绿色，或输入蓝色/红色/紫色/橙色等，
        也可以输入任意十六进制色值（如 #2563eb）」。选定后整站配色统一使用该色系
        （替换下面「样式规范」里的绿色色板，主色/深色/亮色/浅底/框文字/说明文字各取一档
        同色系颜色）；不选则默认绿色。生成后不再问第二次，之后每次更新保持该主题色。
第 0.5 步：问使用者「要不要在网站右下角加一个 AI 助教（可以直接问课程问题/单词意思）？」
        - 使用者**不要** → 复制模板时把 AI 助手的 fab 按钮和聊天面板整段删掉（.ai-fab / #ai-panel
          及相关 JS），网站不带 AI。
        - 使用者**要** → 说明这需要：① 在火山引擎方舟控制台开通一个大模型 API（如
          Doubao-Seed 系列，选「安心体验/免费额度」档，不充值）② 创建推理接入点拿到 API Key
          ③ 把 API Key 存进 Cloudflare Worker 的 secret ④ Worker 里加一个 /api/chat 代理路由
          （浏览器不能直连火山引擎，Key 不能暴露在前端）。引导使用者按 references/deploy-cloudflare.md
          末尾的「AI 助教接入」小节操作；模板里的 AI fab/面板代码保留，只需把 API base、模型名、
          助手称谓改成使用者要的。使用者暂时不想折腾就回到「不要」分支。
第 1 步：先完整读取并理解我提供的 Syllabus 和 PPT。PPT 若是图片型 PDF，要逐页读取图片内容并 OCR，
        不要跳页，不要用「印象」代替实际内容。
        读取后根据 PPT 标题（如 Lecture 3 / Unit 2 / Chapter 5 / Week 3）、讲义页眉或使用者的用语，
        推断本门课的时间线/分类单元类型：Week / Lecture / Class / Unit / Chapter / Module / Topic 等，
        整站统一使用该单元命名（如 Lecture 1..N），不要硬编码成 Week。
第 2 步：规划站点结构——确定页面列表（Syllabus / 单元1..单元N（单元类型用第 1 步推断出的
        命名，如 Lecture / Unit / Week）/ Assignment / 必背 / 复习清单 / 课堂笔记）、
        每个单元的知识点清单（数量、顺序、标题、所属子主题）。
第 3 步：先想清楚每个知识点「怎么解释、怎么举例、怎么排序」，再开始写 HTML；不要边写边想。
第 4 步：按下面的「结构规范」和「样式规范」生成完整 HTML。
第 5 步：把本次内容所有新出现的英文术语追加进右侧「词汇速查」区（中英对照），不要遗漏。
第 6 步：更新「必背」页（按单元分卡片），把本次核心考点浓缩成速记条目。
第 7 步：自查（见「校验清单」），通过后交付文件；若用户要求发布，再按「部署」步骤上线。

## 结构规范
- 顶部 header（深色半透明毛玻璃）：左侧品牌区 = 课程缩写 Logo（如 COM5104 Study Hub，其中
  Study Hub 用主题色）+ 课程全称小字；中间是全局搜索框（带下拉结果面板，显示命中数并可点击跳转）。
- 主体三栏 grid（桌面端）：左栏 220px 目录 / 中栏内容 / 右栏 330px 词汇速查；中栏自适应。
- 左栏顶部放「CourseHub 品牌水印」（.hub-mark 圆形徽标：主题色圆环 + 居中粗体字母 Q，
  如 <div class="hub-mark" title="CourseHub · 用 AI 生成的课程复习站"><span class="hub-mark-q">Q</span></div>，
  圆环 2.5px 主题色、Q 字母用主题色深色档、右下角加一个主题色淡色小圆点装饰，
  宽高 52-56px、水平居中、悬停轻微放大变色）。水印放在左栏最顶部，**不再放「课堂知识点」之类的小标题**
  （因为左栏还包含 Syllabus / 作业 / 必背等，不是纯知识点）。**所有用本 Skill 生成的网站都必须带这个 Q 水印**，
  这是 CourseHub 的品牌标识。水印下面是：第一个链接是 📋 Syllabus；接着是一个可折叠组
  「📚 课程单元 1 – N」（<details class="side-group" open>，默认展开，点击标题可整体收起/展开），
  里面是单元 1..N 的链接（用推断出的单元名：Week / Lecture / Unit 等）；组外依次是 📌 Assignment、⭐ 必背、📋 复习清单、📝 课堂笔记、📅 日程安排。
  单元的序号（如 Lecture 1 / Unit 1 / Week 1）用主题色加粗，主题名用深灰，两者颜色区分开。
- 中栏：每个「页面」是一个 <section class="week-page">，一次只显示一个（JS 切换）。
  每个单元页顶部是深色渐变标题条（unit-head）：左边大标题 + 副标题 + 知识点计数徽标，
  右边「全部展开/收起」按钮 + 本页局部搜索框。
- 知识点用 <details class="panel topic"> 卡片：summary 里放「序号. 标题 ⭐（重点标记）」+
  展开/收起符号 + 复习勾选区（「选」方框，用于批量加入复习清单）+ 「✎ 编辑」按钮 +
  **「已掌握」状态胶囊**；正文 .body 里放详细讲解。默认全部收起（Syllabus 的速览卡除外，
  它默认展开）。
- **「已掌握 / 已完成」胶囊**（.done-chk，放在编辑按钮之后）：灰底灰字显示「未掌握」，
  点击变为绿底白字「✓ 已掌握」（Assignment 卡片为「未完成 / ✓ 已完成」）。
  **关键实现**：胶囊点击必须**在 summary 上用捕获阶段监听拦截**
  （summary.addEventListener('click', handler, true)，handler 里 e.preventDefault() +
  e.stopPropagation() 再切换状态），否则点击胶囊会连带触发卡片展开/收起——这是硬性要求。
  状态存 doneMap（键=知识点 tid，Assignment 用作业标题前 40 字符作 tid），云端同步。
- 每个单元页底部有「📌 其他知识点」虚线框区（extra-zone）：显示用户手动补充的知识点，
  并带一个输入表单（名称 + 详细内容 + 添加按钮），添加后与本次知识点并列展示、可加入复习清单、
  可进入富文本编辑。该区最下方再放一个「📷 课堂图片」上传区（img-zone）：虚线框 + 说明文字，
  支持点击选择文件与拖拽上传，图片以网格缩略图展示，每张右上角有 ✕ 删除按钮、点击图片可放大预览。
  上传的图片前端压缩后跨设备同步（见功能清单与部署文件）。
- Syllabus 页：一个「课程关键信息速览」大卡片（默认展开），内含 4 个分区：
  ① 评分结构（各项占比，用绿色加粗）② 关键时间线（各截止日期，用绿色加粗，均注明截止时刻）
  ③ 小组项目须知 ④ 课堂与工具（教材、平台、格式要求）。
  同时把时间线里的每个关键日期**预置进「📅 日程安排」日历**（quiz/assignment/考试/阅读周等，
  按重要级给颜色：红=重要 橙=提醒 蓝=一般 绿=阅读 紫=考试）。
- 日程安排页：左侧目录点「📅 日程安排」进入，中间主区是一张**大日历**（月视图）：
  顶部「上一月 / 回到今天 / 下一月」按钮；网格 7 列，日期格子带事件彩色圆点；
  选中某天后下方显示当天事件列表（每条可删除）+ 事件添加表单（内容 + 颜色分级选择）。
  事件数据跨设备同步。
- Assignment 页：顶部一条通用要求提示（APA 格式、重复率、迟交扣分等），下面每个作业一个
  知识点卡片，标题写明「作业名（占比 · 截止日期）」。
- 必背页：按单元分卡片，每条一行速记（中英结合）。
- 复习清单页：动态渲染清单，每条 = 标题 + 所属单元标签 + 「Know ✓」按钮 + 可展开的详情区
  （详情直接内嵌在清单里，不用跳回原单元）。
- 课堂笔记页：顶部一个输入区（多行 textarea + 「添加笔记」按钮，Ctrl/⌘+Enter 快速添加），
  下面是笔记列表（每条 = 正文 + 时间戳 + 删除按钮）。笔记与单元无关，是整门课的随手记录；
  每条笔记也可进入富文本编辑态（与知识点同一套编辑器）。
- 右栏「词汇速查」：顶部计数 + 搜索框（可搜英文/中文）+ 手动添加单词区（英文 + 中文两个输入框
  + 添加按钮，重复词给红色提示）+ 单词表容器（每行英文|中文，超高自动滚动，滚轮可滚）。
- 词汇每行右侧两个小功能（均在英文单词右侧，**不随行高变化**）：
  · **重点星标**（.vstar，☆/★）：点击标记重点单词，整行变主题色浅底、英文词变深色；
    星标按钮必须放在英文单词单元格（.vword，position:relative + padding-right:34px）内部
    绝对定位（right:4px;top:50%;translateY(-50%)），**不能定位在整行上**，
    否则写入「我的理解」后行变高、星星会下移错位。
  · **专属解释**（点击英文单词）：展开输入框自由输入该词的具体解释（适合专业术语），
    保存后词行下方显示解释文字（.vnote），可再点击编辑/清除。数据 vnotes 按词条 id 存，云端同步。

## 样式规范
- 整体：黑白灰为基调 + **唯一点缀色 = 主题色（默认绿色，可被使用者选择替换）**。
  禁止花哨渐变色堆砌；除主题色外不再引入其他彩色。
- 背景 #f1f5f9（浅灰）；所有面板 .panel 白底、细边框 #e5e7eb、圆角 14-16px、轻阴影。
- header：深色 rgba(15,23,42,.92) + backdrop blur，白色 Logo，主题色点缀。
- week-head 标题条：linear-gradient(135deg,#111827,#1e293b) 深色渐变，标题白色，副标题浅灰。
- 主题色板（默认绿色为参考，使用者选择其他颜色时按同色系换算成 6 档）：
  · 主色（边框/按钮/高亮底） 默认 #22c55e，如换蓝色则 #3b82f6，红色 #ef4444，紫色 #8b5cf6，橙色 #f97316
  · 深色（重点文字）         默认 #16a34a，取所选颜色更深一档
  · 亮色（徽标/计数）        默认 #4ade80，取所选颜色更浅一档
  · 浅底（浅色背景块）       默认 #f0fdf4，取所选颜色 10% 透明度浅底
  · 框文字（绿框文字）       默认 #047857，取所选颜色深色档
  · 说明文字（提示文字）     默认 #065f46，取所选颜色最深档
- 正文层级颜色（重要，用颜色区分内容层级）：
  · <span class="term">主题色加粗</span> = 核心英文术语
  · <b class="key-point">深色加粗</b> = 重点结论
  · <div class="example">灰底 + 左边深灰竖线框</div> = 例子/举例
  · <div class="tip">浅色底（主题色浅底档）+ 左边主题色竖线框</div> = 记忆技巧/提醒
- 所有按钮、搜索框 focus 态统一主题色；勾选框 accent-color 用主题色主色档。
- 搜索高亮 mark.hl：background 用主题色主色档，color:#fff。
- 移动端（屏幕 <700px）：改为单列布局；右栏词汇速查移到页面底部并恢复显示（不得隐藏）；
  词表高度限 260px；标题条竖排；按钮/输入框全宽。这部分必须写在
  `@media(max-width:700px){...}` 里，与桌面端样式隔离。

## 内容写作规范（每个知识点的标准格式）
对 PPT 里的每个知识点，按这个结构写（可长，务必详细）：
1. 标题：「序号. 英文术语（中文）：一句话点题」，重点考点加 ⭐。
2. 定义段：给出学术/教材定义，英文术语用 .term 绿色加粗。
3. 拆解段（如适用）：用 .key-point 列出要点，配合 <ul>/<ol> 逐条解释，每条说人话。
4. 例子段 .example：「举个例子：」+ 一个具体的、贴近学生生活的场景（能用课上的例子就用课上的）。
5. 记忆段 .tip：「💡 记忆/小技巧：」+ 一句话口诀、记忆公式或联想。
6. 可对比的概念（如定性/定量、演绎/归纳、IV/DV）用 .grid 双栏 .box 并排对比。
7. 涉及数据、时间、百分比、人名、论文引用，必须与原始材料一致，不得编造。

## 功能清单（JS 必须实现）
- 左侧目录点击切换页面（一次只显示一个 section），切换后回到页面顶部；「📚 课程单元 1 – N」
  折叠组点击可整体展开/收起。
- 全局搜索（**必须精准匹配 + 高亮**）：输入时实时过滤所有页面知识点（直接精确到知识点，不按单元粗过滤），
  下拉面板逐条列出「命中知识点」（格式：单元序号 · 知识点标题，最多显示 20 条 + 总数），
  点击某条 → 跳到对应单元页 + **只展开该知识点** + 滚动定位到它 + 把搜索词在正文中
  **用绿色高亮（<mark class="hl">，绿底白字）** 标出；清空输入时移除全部高亮。
  无结果显示空状态。
- 每页局部搜索（**必须高亮**）：只过滤当前页面知识点，命中自动展开，
  并把搜索词在正文中用绿色高亮标出；清空时移除高亮；
  无结果显示「本单元没有匹配内容」。
- 关键词高亮实现要点：用 TreeWalker 遍历文本节点，把匹配词包进
  `<mark class="hl">`（CSS：background:#22c55e;color:#fff;border-radius:4px;
  padding:0 3px;font-weight:600）；切换页面 / 清空搜索时先移除所有 mark.hl 再还原文本；
  搜索词含正则特殊字符时先转义。
- 每页「全部展开/收起」按钮：一键展开或收起本页所有知识点，按钮文字随状态切换。
- 词汇速查搜索 + 手动添加（英文必填、中文可空、重复提示、可删除，存 localStorage）。
- 词汇「重点星标 + 专属解释」（vstar 星标 + vnotes 解释，均存 localStorage 并云端同步，
  结构规范里的定位踩坑照抄）。
````

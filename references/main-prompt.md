# 主提示词（首次建站，整段复制给 AI）

````
你现在是一名资深的「课程笔记网站设计师 + 前端工程师」。你的任务是根据我提供的课程材料
（课程名称、Syllabus、每周 PPT），生成一个【单文件 HTML】的课程复习网站。

## 输入
我会提供：
- 课程名称（英文全称 + 中文译名）
- Syllabus / 课程大纲（PDF 或文字，可选）
- 每周的 PPT / PDF / 讲义（逐周提供，可能含大量图片页，需逐页读取 OCR）

## 总体要求
1. 产物是单个 .html 文件：CSS、JS 全部内联；不引入任何外部资源（无图片、无视频、无 CDN、
   无字体、无框架），保证任何设备打开都正常、离线可用。
2. 语言：全部内容中英对照——标题「英文术语（中文翻译）」，正文用中文，核心英文术语加粗。
3. 每个知识点都要讲得【尽可能详细】：先给学术定义，再用两三句大白话解释，配一个贴近生活的
   例子（example），最后给一个记忆点（tip）。禁止只写一句话摘要。
4. 页面功能要完整：多周分页、全局搜索、每页搜索、词汇速查（可手动加词）、复习清单
   （多选一键加入、页内展开详情、Know 移出）、课堂笔记（随时记录）、每页「全部展开/收起」、
   每页底部「其他知识点」手动补充区、使用说明悬浮 icon、左侧目录 Week 折叠组。

## 生成步骤（严格按顺序）
第 0 步：先问使用者「想要什么主题色？直接回车用默认绿色，或输入蓝色/红色/紫色/橙色等，
        也可以输入任意十六进制色值（如 #2563eb）」。选定后整站配色统一使用该色系
        （替换下面「样式规范」里的绿色色板，主色/深色/亮色/浅底/框文字/说明文字各取一档
        同色系颜色）；不选则默认绿色。生成后不再问第二次，之后每周更新保持该主题色。
第 1 步：先完整读取并理解我提供的 Syllabus 和 PPT。PPT 若是图片型 PDF，要逐页读取图片内容并 OCR，
        不要跳页，不要用「印象」代替实际内容。
第 2 步：规划站点结构——确定页面列表（Syllabus / Week1..WeekN / Assignment / 必背 / 复习清单 /
        课堂笔记）、每个 Week 的知识点清单（数量、顺序、标题、所属子主题）。
第 3 步：先想清楚每个知识点「怎么解释、怎么举例、怎么排序」，再开始写 HTML；不要边写边想。
第 4 步：按下面的「结构规范」和「样式规范」生成完整 HTML。
第 5 步：把本周所有新出现的英文术语追加进右侧「词汇速查」区（中英对照），不要遗漏。
第 6 步：更新「必背」页（按 Week 分卡片），把本周核心考点浓缩成速记条目。
第 7 步：自查（见「校验清单」），通过后交付文件；若用户要求发布，再按「部署」步骤上线。

## 结构规范
- 顶部 header（深色半透明毛玻璃）：左侧品牌区 = 课程缩写 Logo（如 COM5104 Study Hub，其中
  Study Hub 用点缀绿）+ 课程全称小字；中间是全局搜索框（带下拉结果面板，显示命中数并可点击跳转）。
- 主体三栏 grid（桌面端）：左栏 220px 目录 / 中栏内容 / 右栏 330px 词汇速查；中栏自适应。
- 左栏标题叫「课堂知识点」：第一个链接是 📋 Syllabus；接着是一个可折叠组
  「📚 Weeks 1 – N」（<details class="side-group" open>，默认展开，点击标题可整体收起/展开），
  里面是 Week 1..N 的链接；组外依次是 📌 Assignment、⭐ 必背、📋 复习清单、📝 课堂笔记。
  Week 的序号（如 Week 1）用点缀绿加粗，主题名用深灰，两者颜色区分开。
- 中栏：每个「页面」是一个 <section class="week-page">，一次只显示一个（JS 切换）。
  每个 Week 页顶部是深色渐变标题条（week-head）：左边大标题 + 副标题 + 知识点计数徽标，
  右边「全部展开/收起」按钮 + 本页局部搜索框。
- 知识点用 <details class="panel topic"> 卡片：summary 里放「序号. 标题 ⭐（重点标记）」+
  展开/收起符号 + 复习勾选区；正文 .body 里放详细讲解。默认全部收起（Syllabus 的速览卡除外，
  它默认展开）。
- 每个 Week 页底部有「📌 其他知识点」虚线框区（extra-zone）：显示用户手动补充的知识点，
  并带一个输入表单（名称 + 详细内容 + 添加按钮），添加后与本周知识点并列展示、可加入复习清单。
- Syllabus 页：一个「课程关键信息速览」大卡片（默认展开），内含 4 个分区：
  ① 评分结构（各项占比，用绿色加粗）② 关键时间线（各截止日期，用绿色加粗，均注明截止时刻）
  ③ 小组项目须知 ④ 课堂与工具（教材、平台、格式要求）。
- Assignment 页：顶部一条通用要求提示（APA 格式、重复率、迟交扣分等），下面每个作业一个
  知识点卡片，标题写明「作业名（占比 · 截止日期）」。
- 必背页：按 Week 分卡片，每条一行速记（中英结合）。
- 复习清单页：动态渲染清单，每条 = 标题 + 所属周标签 + 「Know ✓」按钮 + 可展开的详情区
  （详情直接内嵌在清单里，不用跳回原周）。
- 课堂笔记页：顶部一个输入区（多行 textarea + 「添加笔记」按钮，Ctrl/⌘+Enter 快速添加），
  下面是笔记列表（每条 = 正文 + 时间戳 + 删除按钮）。笔记与周无关，是整门课的随手记录。
- 右栏「词汇速查」：顶部计数 + 搜索框（可搜英文/中文）+ 手动添加单词区（英文 + 中文两个输入框
  + 添加按钮，重复词给红色提示）+ 单词表容器（每行英文|中文，超高自动滚动，滚轮可滚）。

## 样式规范
- 整体：黑白灰为基调 + **唯一点缀色 = 主题色（默认绿色，可被使用者选择替换）**。
  禁止花哨渐变色堆砌；除主题色外不再引入其他彩色。
- 背景 #f1f5f9（浅灰）；所有面板 .panel 白底、细边框 #e5e7eb、圆角 14-16px、轻阴影。
- header：深色 rgba(15,23,42,.92) + backdrop blur，白色 Logo，主题色点缀。
- week-head 标题条：linear-gradient(135deg,#111827,#1e293b) 深色渐变，标题白色，副标题浅灰。
- 主题色板（默认绿色为参考，使用者选择其他颜色时按同色系换算成 6 档）：
  · 主色（边框/按钮/高亮底） 默认 #22c55e，如换蓝色则 #3b82f6，红色 #ef4444，紫色 #8b5cf6，橙色 #f97316
  · 深色（重点文字）         默认 #16a34a，取所选颜色更深一档
  · 亮色（徽标/计数）        默认 #4ade80，取所选颜色更浅一档
  · 浅底（浅色背景块）       默认 #f0fdf4，取所选颜色 10% 透明度浅底
  · 框文字（绿框文字）       默认 #047857，取所选颜色深色档
  · 说明文字（提示文字）     默认 #065f46，取所选颜色最深档
- 正文层级颜色（重要，用颜色区分内容层级）：
  · <span class="term">主题色加粗</span> = 核心英文术语
  · <b class="key-point">深色加粗</b> = 重点结论
  · <div class="example">灰底 + 左边深灰竖线框</div> = 例子/举例
  · <div class="tip">浅色底（主题色浅底档）+ 左边主题色竖线框</div> = 记忆技巧/提醒
- 所有按钮、搜索框 focus 态统一主题色；勾选框 accent-color 用主题色主色档。
- 搜索高亮 mark.hl：background 用主题色主色档，color:#fff。
- 移动端（屏幕 <700px）：改为单列布局；右栏词汇速查移到页面底部并恢复显示（不得隐藏）；
  词表高度限 260px；标题条竖排；按钮/输入框全宽。这部分必须写在
  `@media(max-width:700px){...}` 里，与桌面端样式隔离。

## 内容写作规范（每个知识点的标准格式）
对 PPT 里的每个知识点，按这个结构写（可长，务必详细）：
1. 标题：「序号. 英文术语（中文）：一句话点题」，重点考点加 ⭐。
2. 定义段：给出学术/教材定义，英文术语用 .term 绿色加粗。
3. 拆解段（如适用）：用 .key-point 列出要点，配合 <ul>/<ol> 逐条解释，每条说人话。
4. 例子段 .example：「举个例子：」+ 一个具体的、贴近学生生活的场景（能用课上的例子就用课上的）。
5. 记忆段 .tip：「💡 记忆/小技巧：」+ 一句话口诀、记忆公式或联想。
6. 可对比的概念（如定性/定量、演绎/归纳、IV/DV）用 .grid 双栏 .box 并排对比。
7. 涉及数据、时间、百分比、人名、论文引用，必须与原始材料一致，不得编造。

## 功能清单（JS 必须实现）
- 左侧目录点击切换页面（一次只显示一个 section），切换后回到页面顶部；「📚 Weeks 1 – N」
  折叠组点击可整体展开/收起。
- 全局搜索（**必须精准匹配 + 高亮**）：输入时实时过滤所有页面知识点（不是按周过滤），
  下拉面板逐条列出「命中知识点」（格式：Week 序号 · 知识点标题，最多显示 20 条 + 总数），
  点击某条 → 跳到对应 Week 页 + **只展开该知识点** + 滚动定位到它 + 把搜索词在正文中
  **用绿色高亮（<mark class="hl">，绿底白字）** 标出；清空输入时移除全部高亮。
  无结果显示空状态。
- 每页局部搜索（**必须高亮**）：只过滤当前页面知识点，命中自动展开，
  并把搜索词在正文中用绿色高亮标出；清空时移除高亮；
  无结果显示「本周没有匹配内容」。
- 关键词高亮实现要点：用 TreeWalker 遍历文本节点，把匹配词包进
  `<mark class="hl">`（CSS：background:#22c55e;color:#fff;border-radius:4px;
  padding:0 3px;font-weight:600）；切换页面 / 清空搜索时先移除所有 mark.hl 再还原文本；
  搜索词含正则特殊字符时先转义。
- 每页「全部展开/收起」按钮：一键展开或收起本页所有知识点，按钮文字随状态切换。
- 词汇速查搜索 + 手动添加（英文必填、中文可空、重复提示、可删除，存 localStorage）。
- 复习清单：每个知识点 summary 右侧有「选」勾选框 → 勾选后页面底部出现悬浮条
  「已选 N 个 → 加入复习清单 → 清空选择」一键批量加入；已加入的显示「已加入 ✓」并锁定勾选框；
  复习清单页点击条目直接展开详情，点「Know ✓」移出清单。数据存 localStorage。
- 课堂笔记：textarea + 按钮添加笔记（带时间戳），列表每条可删除，存 localStorage。
- 每页「其他知识点」表单：添加后渲染为本页普通知识点卡片（带删除按钮），可搜索、可加入清单。
- 使用说明：页面右上角一个绿色圆圈「?」icon，鼠标悬停（移动端点击）弹出用法说明浮层。
- 知识点计数徽标：每个 Week 页标题右侧显示「N 个知识点」。
- localStorage 键名建议：review_list / extra_notes / vocab_add / course_notes
  （键名前缀用课程缩写防冲突）。

## 数据同步说明（生成时必须遵守）
- 首次生成时**不要在代码里擅自加入云端同步**（需要额外部署 Worker，见
  references/deploy-cloudflare.md）。生成完先把网站交付给使用者，然后**主动询问**：
  「需要我帮你免费部署上线并开启跨设备同步吗？」
- 使用者**需要** → 按 references/deploy-cloudflare.md 的「跨设备同步版」实现
  pushToCloud（800ms 防抖 PUT）/ loadFromCloud（GET）+ **版本号方向判断**，
  并在交付说明里写清楚「已部署，所有设备数据同步」。
- 使用者**不需要** → 在交付说明里**明确提醒**：「未部署 = 纯本地文件，
  复习清单 / 单词 / 笔记只保存在当前浏览器 localStorage，换设备 / 换浏览器 / 清缓存
  不会同步或会丢失；需要跨设备同步时告诉我，我再帮你部署。」

## 校验清单（交付前逐项自查）
1. 文件是单个 .html，无任何外部资源引用。
2. 知识点数量、顺序、标题与 PPT 一致；日期、百分比、人名与 Syllabus 一致。
3. 每个知识点都有：定义 + 通俗解释 + 例子 + 记忆点（缺一不可）。
4. 全局搜索、每页搜索、词汇搜索、全部展开/收起、复习清单（勾选→批量加入→展开→Know）、
   课堂笔记（添加→删除→刷新保留）、手动加词、手动加知识点，全部功能在浏览器里实测可用；
   全局搜索输入关键词后，下拉只列出「命中的知识点」（不是整周），点击后跳转并只展开该知识点，
   且正文中搜索词是绿色高亮（mark.hl）状态。
5. 桌面端三栏布局正常；用浏览器开发者工具切到手机宽度（375px）检查：单列、无横向滚动、
   词汇速查可见、标题条不溢出。
6. 默认落地页是 Syllabus，速览卡展开，其余全部收起。
7. 刷新页面后，手动添加的单词 / 知识点 / 复习清单 / 课堂笔记仍在（localStorage 生效）。
````

# 每周更新提示词（每周发 PPT 时，整段复制给 AI）

````
这是本周的课程 PPT（Week X）。请把内容更新进我们现有的复习网站：
1. 先逐页读完 PPT（图片页要 OCR，不要跳页）。
2. 新增该周的知识点卡片：按既有格式（定义 + 通俗解释 + 例子 + 记忆点 + 中英对照）写入
   Week X 页面；标题格式、颜色层级、⭐ 标记规则与之前的周完全一致。
3. 新出现的英文术语追加进右侧「词汇速查」，并补充计数。
4. 更新「必背」页：新增 Week X 必背卡片。
5. 若 PPT 提到新的作业 / 截止日期 / 评分变化，同步更新 Syllabus 页和 Assignment 页
   （Assignment 用「作业名（占比 · 截止日期）」格式，不用编号概括）。
6. 本周左侧目录「📚 Weeks 1 – N」折叠组里的「Week X · 主题名」补上实际主题（不再是 TBA）。
7. 自查功能与布局（校验清单同上），然后交付/重新部署，线上链接保持不变。
8. 若该网站之前**未部署**（使用者一直用本地文件），更新完成后顺带提醒使用者：
   「目前是纯本地文件，复习清单/单词/笔记只在当前浏览器保存，换设备不会同步；
   需要的话我可以帮你免费部署并开启跨设备同步。」
注意：不要改动其他周的内容、不要改动配色与桌面端布局（保持首次生成时选定的主题色不变）、
不要清空用户手动添加的数据（复习清单 / 单词 / 其他知识点 / 课堂笔记）。
````

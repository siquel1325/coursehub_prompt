# 🎓 CourseHub · 把 PPT 变成你的专属复习网站

> **上课听不懂、课后没时间整理笔记？让 AI 帮你把 PPT 变成随时能复习的网站。**
> 你只需要每次丢一份新 PPT 进来，剩下的事全部交给 AI。

---

## 为什么会有它？

留学生的日常大概是这样的：

- 🗣 全英文授课，老师语速飞快，一节课 60+ 页 PPT 翻完就没了
- 📝 课上听懂了 70%，课后想整理笔记，发现根本挤不出时间
- 😵 考前复习，面对一堆 PPT 和零散笔记，不知道从哪看起

**CourseHub 就是为了解决这件事**：你给 AI 一份 PPT + 课程大纲，它还你一个**结构完整、内容详实、免费上线、全设备同步**的专属复习网站。

它不只是留学生的工具——只要你的学习里有 PPT、课程大纲或上课笔记，课后需要复习和理解，都可以用。

## 它能帮你做什么？

- 🧠 **每个知识点都讲透**：定义 + 大白话解释 + 生活例子 + 记忆口诀，不用自己再查资料
- 📚 **整门课一个站**：Syllabus / 各单元知识点 / 作业 / 必背速记 / 复习清单 / 课堂笔记，全在一处
- 🔍 **搜得到、看得清**：全局 / 按单元 / 单词表三级搜索，搜索词在正文里直接**绿色高亮**，点结果直达对应知识点
- ✅ **复习清单**：上课勾选没听懂的知识点 → 一键批量加入清单 → 清单里直接展开详情复习 → 学会了点「Know ✓」划掉
- 📝 **课堂笔记**：随时记两笔，还能像 Word 一样**加粗 / 高亮 / 变色 / 画框**，和复习清单、单词一样全设备同步
- ✏️ **富文本编辑**：任何知识点（包括你自己补充的）都能进入编辑模式——三色高亮、蓝黄字色、有序/无序列表、灰绿蓝红黄五种重点框，把笔记变成你自己的排版
- 📅 **日程安排日历**：Syllabus 里的 Quiz / Assignment / 考试 / 阅读周自动标进日历（红橙蓝绿紫按重要度分级），老师临时提的重要节点也可以自己加、自己删
- 📷 **课堂图片上传**：拍下黑板 / 白板 / 屏幕，拖进来就存到云端，任何设备打开都能看到，随时可删
- 🎨 **主题色可选**：生成前告诉 AI 你喜欢的颜色，整站统一换色（默认绿色）

👉 **在线示例（点开即用）**：https://com5104-study-hub.zsq040513.workers.dev

## 支持哪些 AI？

| 使用方式 | 适合的 AI |
|---|---|
| **安装 Skill（推荐）** | 支持 Skill 机制的 AI：**豆包**、**Claude Code / Claude Desktop**、**Cursor**，以及任何遵循 `SKILL.md` 目录约定的 AI 工具 |
| **复制提示词（零安装）** | 所有其他 AI：**ChatGPT / Gemini / Kimi / 文心一言**……打开 `references/main-prompt.md` 整段复制给它即可 |

两种方式生成的效果完全一样，选哪种都行。

## 快速开始（约 1 分钟）

### 方式一：安装 Skill（推荐）

1. **下载**：点右上角绿色 `Code` → `Download ZIP`，解压；或 `git clone https://github.com/siquel1325/coursehub_prompt.git`
2. **放入技能目录**：把仓库内容放进你所用 AI 的 skills 目录，例如：
   - 豆包：用户技能目录（`...\.doubao\agent_mode\workspace\.user_skills\coursehub\`）
   - Claude Code：`~/.claude/skills/coursehub/`
   - Cursor：`.cursor/skills/coursehub/`
3. **使用**：对你的 AI 说——「**根据这次的 PPT 生成课程复习网站**」
4. **选主题色**：AI 会问你想要什么颜色，直接回车用默认绿色，或输入「蓝色 / 红色 / 紫色」等
5. **完成**：让 AI 帮你**免费部署上线**，得到一个链接，分享给同学、放进收藏夹

> 💡 **更省事的方式：直接把 Skill 发给 AI 装**。很多支持 Skill 的 AI 允许你把
> `SKILL.md` 这个文件（或整个仓库压缩包）直接拖给它，然后说一句
> 「**帮我把这个 Skill 安装到你的技能目录**」——AI 会自己完成拷贝和配置，你完全不用碰文件夹。
> 注意：**不是所有 AI 都支持这样做**（有些 AI 没有权限访问自己的技能目录），如果它说做不到，
> 按上面第 1-2 步手动放一下就行，效果完全一样。鼓励先试试直接发给它，不行再手动装。

### 方式二：复制提示词（不用装任何东西）

1. 打开 [`references/main-prompt.md`](references/main-prompt.md)
2. 全选 → 复制
3. 粘贴给任何 AI，同时附上你的 PPT / 课程大纲
4. 同样能得到完整网站

## 每周课堂新内容（新PPT/笔记）怎么更新？

每次有了新内容（新的一周 / 新的 Lecture / 新的 Unit / 新的 Chapter……），把新 PPT 发给 AI，
说一句：「**更新到最新一单元**」（也可以直接说「更新到 Lecture 3」「更新到 Unit 2」）

AI 会自动完成：读 PPT → 新增本次知识点 → 补充新单词 → 更新必背页 → 重新部署。
**线上链接保持不变**，你收藏的地址永远能用。

> 💡 **关于"每周"**：CourseHub 不限定只能用 Week 分类。时间线 / 分类单元完全跟着你的课程走——
> 你的 PPT 标题叫 Lecture 3，网站就是 Lecture 1..N；叫 Unit 2 就是 Unit 1..N；
> 叫 Week 3 才是 Week 1..N。AI 会根据 PPT 标题和你的用语自动判断，全程不用你手动指定。

## 数据会丢吗？

| 情况 | 结果 |
|---|---|
| 不部署（本地打开 HTML） | 数据存在当前浏览器的 localStorage，**本设备刷新不丢**，但换设备 / 换浏览器**不同步** |
| 部署 + 开启同步（免费，推荐） | 数据存云端（Cloudflare 免费额度），**任何设备、任何浏览器打开同一链接，看到同一份数据**（复习清单 / 单词 / 笔记 / 富文本编辑 / 日历日程 / 课堂图片全部同步） |

AI 生成完网站后会**主动问你要不要免费部署**——需要就一步到位开启全设备同步；不需要它会明确告诉你不同步的后果。部署教程详见 [`references/deploy-cloudflare.md`](references/deploy-cloudflare.md)。

## 主题色

生成时 AI 会问你想用什么主题色：

- 直接回车 → 默认**绿色**
- 输入「**蓝色 / 红色 / 紫色 / 橙色**」等 → 整站统一换成该色系
- 输入任意色值（如 `#2563eb`）→ 整站用这个颜色
